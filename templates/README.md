# 🎫 `templates/`

> Default ticket templates

<sub>[🏠 Home](../README.md) › **templates/**</sub>

| File | Purpose |
|---|---|
| `incident-ticket.md` | Default ticket template, used when a customer has none. Placeholders are documented in `docs/tickets.md`. |
| `soc-standard-ticket.md` | SOC standard format: Subject, Description/outcome, When (UK time), Who, Where, Why, Additional details, Action taken by SOC, Action for client. New customers start with it; load it for an existing customer in **Ticket template** → **Load starter**. |
